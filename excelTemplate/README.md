# Excel 导出模板

默认模板文件名：`飞书排班模板.xlsx`。

发布包不包含现有模板文件。实际导入前，需要自行放入目标考勤组包含姓名和 UID 的当前排班表；程序不会为成员编造 UID。

请在飞书假勤目标考勤组中，通过“排班表 → 导入/导出 → 当前排班表”下载 `.xlsx`，放入本目录并改为上述名称。公开帮助中心只有操作说明，模板由登录后的考勤组生成，并非通用空白文件。

官方说明：https://www.feishu.cn/hc/zh-CN/articles/360049067384

程序启动后在“设置 → 导出设置 → Excel导出模板”下拉框中选择一个模板；默认使用 `飞书排班模板.xlsx`。下拉框最后一项“打开模板文件夹…”可直接打开本目录，并保留原先选择的模板。其他 `.xlsx` 文件也必须直接放入本目录，不能使用外部路径、文件链接或子目录。飞书导出所选模板需要包含 UID、姓名和日期列；原表头和人员标识请保留。

点击“生成 → 导出飞书排班表...”后先选择保存位置，再填写班次对应关系。程序会自动读取设置中选择的模板。缺少模板时会显示具体文件名和目录，不会用虚构 UID 生成文件。

开发构建会复制源码中的本地模板供调试；安装打包时只创建 `excelTemplate` 目录和本说明，不携带本地模板文件。程序运行时只读取自身旁边的这个目录；使用打包版时可通过设置下拉框最后的“打开模板文件夹…”定位。

真实考勤组模板可能包含姓名、UID、工号、部门和既有排班。请勿将带真实数据的文件提交到公开代码库。自行制作的空白模板可以随项目公开；第三方模板还需遵守其授权要求。
